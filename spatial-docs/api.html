API Reference

Everything Spatial exposes on server and client.

Require

local Spatial = require(ReplicatedStorage.Spatial)

Spatial.Client  -- client API (nil on server)
Spatial.Server  -- server API (nil on client)
Spatial.Types   -- shared type exports
Server bootstrap Require Spatial once on the server so remotes and pose history exist before any client talks.

Configuration

Client:Configure({ Debug = true })

Server

local Server = require(...).Server

Configure

Server.Configure(patch: { [string]: any })

Override config keys. Unknown keys are ignored and logged.

Create

Server.Create(params: HitboxParams): Hitbox

Create a new hitbox. See HitboxParams.

Get

Server.Get(id: string): Hitbox?

Retrieve a live hitbox by ID.

Track / Untrack

Server.Track(model: Model)
Server.Untrack(model: Model)

Begin or stop recording pose history for lag compensation. Every potential target must be tracked.

Ping / Now / Metrics / Health / SetAliveFolder

Server.Ping(player: Player): number
Server.Now(): number
Server.Metrics(): { ... }
Server.Health(): { ... }
Server.SetAliveFolder(folder: Instance)

Latency, synchronized time, counters, diagnostics, and optional alive-folder filter.

DebugHook

Server.DebugHook.SetEnabled(on: boolean)
Server.DebugHook.Enabled(): boolean

Studio helpers for markers and metric dumps.

Client

local Client = require(...).Client

Configure

Client.Configure(patch: { [string]: any })

Same as server Configure.

Create

Client.Create(params: HitboxParams): Hitbox

Create a predictive hitbox. Automatically blacklists the local character when possible.

Prediction only Do not apply damage from client Hit. Wait for server confirmation.

Get / Now

Client.Get(id: string): Hitbox?
Client.Now(): number

DebugHook

Client.DebugHook.SetEnabled(on: boolean)
Client.DebugHook.Enabled(): boolean

Types

HitboxParams

All fields optional; defaults from Config.

{
    Shape: "Box" | "Sphere" | "Part",
    Size: Vector3,           -- Box
    Radius: number,          -- Sphere
    Part: BasePart,          -- Part shape
    CFrame: CFrame,          -- world origin
    Origin: BasePart,        -- follow this part
    Offset: CFrame,          -- relative to Origin
    Duration: number,
    Mode: "Once" | "Pierce" | "Cooldown",
    Debounce: number,
    Filter: {
        Whitelist: { Instance }?,
        Blacklist: { Instance }?,
        AliveFolder: Instance?,
        CollisionGroup: string?,
        LookingFor: "Humanoid" | "Player" | "Model",
    },
    Authority: "Server" | "Client" | "Hybrid",
    Owner: Player?,
    LagCompensate: boolean?,
    VelocityPrediction: boolean?,
    MaxRewind: number?,
    Debug: boolean?,
    Id: string?,
    DotProduct: number?,
    ReferenceLook: Vector3?,
}

HitResult

{
    Model: Model,
    Humanoid: Humanoid?,
    Player: Player?,
    Part: BasePart,
    Position: Vector3,
    Confirmed: boolean,   -- true after server validation
    Rewound: boolean,     -- lag compensation applied
    Latency: number,
}

Enums

ModeBehaviour
OnceFirst valid hit per target
PierceHit every valid target each query
CooldownSame target again after Debounce
