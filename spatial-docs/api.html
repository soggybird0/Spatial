API reference

Everything Spatial exposes on server and client.

local Spatial = require(ReplicatedStorage.Spatial)
Spatial.Client   -- nil on server
Spatial.Server   -- nil on client
Spatial.Types
Bootstrap Require once on the server before any client uses Spatial.

Server

Configure

Server.Configure(patch)

Patch config keys. Unknown keys are ignored.

Create

Server.Create(params: HitboxParams) → Hitbox

Spawn a hitbox. See HitboxParams below.

Get

Server.Get(id: string) → Hitbox?

Track / Untrack

Server.Track(model: Model)
Server.Untrack(model: Model)

Pose history for lag compensation. Track every potential target.
