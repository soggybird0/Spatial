# Spatial Docs

Static HTML documentation for Spatial.

## Structure

```
spatial-docs/
├── index.html      # Overview, install, quick start
├── api.html        # Full API reference
├── examples.html   # Code examples
├── css/styles.css
├── js/main.js
└── assets/icon.png
```

## Hosting

Drop this folder into your repo (e.g. `spatial-docs/`) and enable GitHub Pages
from the branch, pointing at `/spatial-docs` (or use a `/docs` folder).

Live URL shape:
`https://<user>.github.io/<repo>/spatial-docs/`
