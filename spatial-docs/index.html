Shared hitbox library · v1.0.2

Spatial — hitboxes that actually check where you were.

Server + client hitboxes with lag compensation, velocity prediction, and fail-closed validation. Not another .Touched wrapper — a system that rewinds the world before it decides.

Lag compensation Hybrid authority Luau strict MIT
Quick start API reference

Why not just .Touched?

⟲

Rewind, then test

Server rolls target poses back to the claim timestamp before intersection checks.

↯

Predict on client

Instant VFX from local queries. Damage only after the server confirms.

⛨

Fail closed

Rate limits, stale/future timestamps, no-intersect — explicit reject reasons.

↔

Shapes that move

Box, sphere, or part. Weld to weapons. Origin + offset follow every frame.

𓍝

Budgeted

Hard caps on queries per frame and claims per player so combat stays cheap.

☕︎

Typed end to end

Strict Luau types for params, results, modes, and authority.

Install

[dependencies]
Spatial = "soggybird0/spatial@1.0.2"

1. Claim the asset on the Creator Store.

2. Open Roblox Studio and insert the model via the Toolbox (Inventory > My Models).

3. Parent the Spatial folder under ReplicatedStorage to begin using it in your scripts.

-- Drop under ReplicatedStorage; require on server + client
local Spatial = require(ReplicatedStorage.Spatial)

Quick start

Require Spatial once on the server so remotes and pose history exist before clients talk.

Server — authoritative hit

local Server = require(ReplicatedStorage.Spatial).Server

local hitbox = Server:Create({
    Shape = "Box",
    Size = Vector3.new(6, 6, 8),
    Origin = character.HumanoidRootPart,
    Offset = CFrame.new(0, 0, -4),
    Duration = 0.25,
    Authority = "Hybrid",
    Owner = player,
})

hitbox.Hit:Connect(function(result)
    if result.Humanoid then
        result.Humanoid:TakeDamage(25)
    end
end)

hitbox:Start()

Client — predictive feedback

local Client = require(ReplicatedStorage.Spatial).Client

local hitbox = Client:Create({
    Shape = "Sphere",
    Radius = 5,
    Origin = character.HumanoidRootPart,
    Duration = 0.2,
})

hitbox.Hit:Connect(function(result)
    playHitEffect(result.Position) -- VFX only
end)

hitbox:Start()
Rule of thumb Damage and gameplay state only from Spatial.Server.Hit. Client hits are for feel.

Authority modes

Mode Client queries Server queries Best for
"Server" No Yes Projectiles, AOE
"Client" Yes No* Snappy melee
"Hybrid" Yes Yes Default — both worlds

* Client-authority nodes still exist on the server so claims have somewhere to land.

How it works

  1. Client (or server) runs spatial queries — never .Touched.
  2. Client sends a claim: hitbox id, timestamp, victim tokens.
  3. Server rate-limits, rewinds tracked poses, re-tests the volume.
  4. Emits confirmed Hit or Rejected with a reason. Fail closed.

Configuration

Server:Configure({
    MaxRewind = 0.5,
    QueriesPerFrame = 48,
    ClaimRate = 18,
    Debug = false,
})
Key Default Notes
MaxRewind 0.5 Max seconds of rewind
HistorySeconds 1 Pose buffer length
HistoryHz 20 Snapshot rate
QueriesPerFrame 48 Hard query budget
ClaimRate 18 Claims / sec / player
DefaultAuthority "Hybrid" Server / Client / Hybrid

Tracking targets

Players.PlayerAdded:Connect(function(player)
    player.CharacterAdded:Connect(function(character)
        Server:Track(character)
    end)
end)

Server:Track(npcModel)
Server:Untrack(npcModel)

No track → no rewind for that model. Owners are tracked automatically when you pass Owner.

Server.DebugHook:SetEnabled(true)
